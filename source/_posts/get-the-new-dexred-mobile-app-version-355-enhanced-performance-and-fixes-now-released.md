## Get the New DEX/RED Mobile App Version 3.5.5: Enhanced Performance & Fixes Now Released!

[![3.5.5 DJ Software Updates](https://i0.wp.com/pcdj.com/wp-content/uploads/2015/12/djsoftware355updates-coverimage.jpg?resize=530%2C298&ssl=1)](https://i0.wp.com/pcdj.com/wp-content/uploads/2015/12/djsoftware355updates-coverimage.jpg?fit=530%2C298&ssl=1 "DJ Software updates 3.5.5")

DEX 3.5.5 and Red Mobile 3.5.5 **DJ mixing software** updates are now available for both Mac and Windows.

Both **free updates for existing users** address a previous issue logging in to or registering a [Pulselocker](https://tools.techidaily.com/pcdj/products/) account using Facebook login, and **a number of bug fixes and performance improvements.**

[Learn More About Pulselocker ![DEX 3.5.5 and RED Mobile 3.5.5 with pulselocker](https://i0.wp.com/pcdj.com/wp-content/uploads/2015/12/pcdjpulslocker-pressrelease-sml.jpg?fit=450%2C253&ssl=1 "dex 3.5.5 with pulselocker and key detection")](https://tools.techidaily.com/pcdj/products/)

**Brand** **new in DEX 3.5.5 is Key Detection for harmonic mixing** (key detection must be turned on under the general tab in DEX 3.5.5’s options). Key is displayed in the key box/area located in each DEX 3.5.5 deck as well as in the browser. **Key displayed before the ‘/’ is a variant of the Camelot scale, after the ‘/’ is the music notation.** You can also **search specifically for ‘key’ values** within DEX 3.5.5 by typing in a ‘k’ previous to your search, IE: k035
